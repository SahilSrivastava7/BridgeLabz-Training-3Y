URI Encoding

Reserved characters and JavaScript encoding functions

Reserved Characters

CharacterEncoded ValueExample
Space%20Hello World → Hello%20World
#%23page#section → page%23section
&%26name=Tom&age=25 → name=Tom%26age=25
?%3Fsearch?q=test → search%3Fq%3Dtest
/%2Ffolder/file → folder%2Ffile

encodeURI() vs encodeURIComponent()

let url = "https://example.com/search?q=HTML & CSS";
let encodedURL = encodeURI(url);

let component = "HTML & CSS";
let encodedComponent = encodeURIComponent(component);
