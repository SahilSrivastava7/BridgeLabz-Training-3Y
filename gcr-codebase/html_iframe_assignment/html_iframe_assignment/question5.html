HTML Entities

Displaying reserved and special characters safely

What Are HTML Entities?

Entities allow reserved characters to be displayed without breaking HTML structure.

Format: &entity_name; or &#entity_number;

CharacterEntity NameNumeric CodeExample
<&lt;&#60;Displays <
>&gt;&#62;Displays >
&&amp;&#38;Displays &
"&quot;&#34;Displays "
'&apos;&#39;Displays '
©&copy;&#169;Displays ©
®&reg;&#174;Displays ®
€&euro;&#8364;Displays €
™&trade;&#8482;Displays ™

Usage Example

<p>HTML stands for &lt;HyperText Markup Language&gt;
&amp; is fun!</p>
