Iframe Security

Sandbox, HTTPS and referrer policy

Security Risks

  • Clickjacking
  • XSS
  • Phishing
Avoid embedding untrusted content without restrictions.

Restricted Iframe

<iframe
  src="https://example.com"
  sandbox="allow-scripts allow-same-origin"
  referrerpolicy="no-referrer">
</iframe>

Use HTTPS URLs, limit permissions, use sandbox, and set referrerpolicy.
