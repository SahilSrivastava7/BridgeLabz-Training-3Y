HTML Frames (Legacy)

What Were Frames?

  • Frames divided the browser window into multiple sections.
  • Each section could display a different HTML document.
  • Different frames could be scrolled or navigated independently.
The PDF states that frames are deprecated in HTML5.

Legacy Example

<frameset cols="30%,70%">
  <frame src="menu.html">
  <frame src="content.html">
</frameset>

Modern pages should use semantic HTML + CSS for layout and <iframe> for embedded content.
