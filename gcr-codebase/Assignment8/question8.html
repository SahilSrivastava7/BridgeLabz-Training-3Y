Box-Sizing Comparison

Same declared width and padding, two very different results

content-box (default)

width: 200px + padding adds extra size on top of it.

border-box

width: 200px includes the padding, so it stays 200px total.

By default, an element's width only defines the content area — padding and border are added on top, making the element visually larger than its declared width. With box-sizing: border-box, the padding and border are included inside that declared width, so the element's total rendered size never exceeds what you specified. Both boxes above have the exact same width and padding values, but the default box ends up visibly wider than the border-box one.
